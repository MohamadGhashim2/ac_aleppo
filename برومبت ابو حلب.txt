# برومبت شامل لفهم مشروع **ac_aleppo** بدون فتح GitHub

انسخ البرومبت التالي كما هو وأرسله لأي نموذج ذكاء اصطناعي:

---

أنت محلّل تقني وسيو وخبير نمو رقمي. أريدك أن تتعامل مع الوصف التالي على أنه **مرجع المشروع الرسمي**، ثم تُنتج لي تحليلًا احترافيًا كاملًا ومنظمًا.

## 1) تعريف المشروع
المشروع عبارة عن موقع عربي (RTL) تسويقي/تحويلي لورشة **تكييف سيارات في الرياض** تحت علامة “أبو حلب / العاصمة حلب”، هدفه:
- جذب زيارات عضوية من Google عبر صفحات خدمات ومقالات بحثية.
- تحويل الزائر إلى Lead عبر **واتساب** أو **اتصال مباشر**.
- تتبع مصادر الزيارات والحملات الإعلانية وقياس التحويلات (GA + Google Ads).

الموقع مبني كـ **SPA** باستخدام React + Vite مع راوتر بسيط يعتمد على `window.location.pathname` بدل مكتبة راوتنج خارجية.

## 2) الجمهور المستهدف
- أصحاب السيارات في الرياض الباحثين عن:
  - تعبئة فريون
  - كشف تهريب
  - إصلاح كمبروسر
  - ضعف تبريد وقت الظهر
  - رائحة المكيف
- جمهور قادم من البحث العضوي + حملات ممولة + واتساب.

## 3) الفكرة التجارية (Business Model)
- صفحة رئيسية Landing تُبرز الخدمة، الثقة، المعرض، الأسئلة الشائعة، وأزرار التواصل.
- صفحة خدمات مخصصة لتغطية نية شراء واضحة (Commercial Intent).
- صفحات مقالات تستهدف كلمات أعراض ومشاكل (Informational Intent) ثم تدفع إلى CTA.
- جميع الصفحات تدعم التحويل إلى اتصال/واتساب مع tracking attribution.

## 4) المكدس التقني (Tech Stack)
- **Frontend:** React 19
- **Build Tool:** Vite (rolldown-vite)
- **Styling:** CSS مخصص داخل المشروع
- **Animation/UI libs:** AOS + Framer Motion
- **Linting:** ESLint 9
- **Deployment:** إعداد Vercel موجود
- **Assets:** صور WebP + أيقونات SVG + خطوط عربية محلية (Tajawal / Ara-Hamah)

## 5) البنية المعمارية (Architecture)
- Entry: `src/main.jsx`
- Router layer: `src/RootRouter.jsx`
  - المسارات الأساسية:
    - `/` الصفحة الرئيسية
    - `/services`
    - `/articles`
    - `/articles/why-ac-not-cooling-riyadh`
    - عدة صفحات مقالات إضافية عبر `SimpleArticlePage`
- Layout داخلي موحّد للصفحات الفرعية عبر `InnerPageLayout`.

## 6) SEO الحالي (مهم جدًا)
### On-Page SEO
- Hook مخصص `useSeoMeta` لإدارة:
  - `title`
  - `meta description`
  - `canonical`
  - Open Graph (og)
  - Twitter cards
- Hook `useJsonLd` لإضافة Structured Data (JSON-LD) ديناميكيًا.
- صفحة الخدمات والمقالات لها metadata مخصص.
- الصفحة الرئيسية لديها حالة Landing خاصة (`/best-car-ac-repair-riyadh`) بعنوان ووصف مختلفين.

### Technical SEO
- وجود `robots.txt` و `sitemap.xml` داخل `public`.
- استخدام عناوين URL عربية/إنجليزية موجهة للبحث المحلي في الرياض.
- صور كثيرة بصيغة WebP (تحسين الأداء).
- Canonical مضبوط على مستوى الصفحة عبر الهوك.

### Content SEO
- Cluster محتوى مشاكل تكييف شائعة:
  - عدم التبريد
  - تهريب الفريون
  - فصل/تشغيل متكرر
  - ضعف وقت الظهر
  - الروائح
- هذا يدعم استراتيجية Topic Cluster + Internal Linking إلى صفحة الخدمات.

## 7) التحليلات والتتبع (Analytics & Attribution)
يوجد ملف `analytics.js` يتضمن:
- التقاط first-touch attribution وتخزينه في `localStorage`.
- قراءة UTM parameters + gclid/fbclid.
- إرفاق بيانات المصدر مع أحداث:
  - page_view
  - lead_click
- تتبع نقرات CTA (واتساب/اتصال) وإرسالها عبر `gtag`.

وفي الصفحة الرئيسية:
- أحداث Google Ads conversion منفصلة لواتساب واتصال.
- callback للتأكد من إرسال التحويل قبل التنقل إلى WhatsApp/tel.

## 8) التحويل وتجربة المستخدم (CRO/UX)
- CTA واضحة ومتكررة (Header + Sections + صفحات داخلية).
- رقم الهاتف وروابط واتساب/الموقع الجغرافي جاهزة في config موحد.
- تصميم عربي مناسب لجمهور محلي.
- وجود معرض أعمال وFAQ لبناء الثقة.

## 9) الإعدادات المركزية
ملف `siteConfig.js` يحتوي:
- `SITE_URL`
- `PHONE`
- `LOCATION_LINK`
- دالة `getWhatsAppUrl` لتوليد رابط الرسالة تلقائيًا.

## 10) المطلوب منك كمحلّل
بناءً على الوصف أعلاه، قدّم لي المخرجات التالية بترتيب واضح:
1. **Executive Summary** من 8-12 نقطة.
2. **تفكيك معماري** يشرح تدفق المستخدم من الدخول حتى التحويل.
3. **تقييم SEO شامل** (On-page / Technical / Content / Local SEO) مع:
   - نقاط قوة
   - فجوات
   - أولويات تحسين (Quick Wins vs Long-Term)
4. **خطة محتوى 90 يوم**:
   - عناقيد كلمات مفتاحية (TOFU/MOFU/BOFU)
   - أفكار مقالات وصفحات خدمة/موقع
   - قالب Internal Linking مقترح
5. **خطة CRO** لرفع التحويل من الزيارات الحالية.
6. **خطة قياس Analytics**:
   - Event taxonomy موحّدة
   - Funnel مقترح
   - Dashboard KPIs
7. **خريطة تنفيذ عملية** لمدة 4 أسابيع (Week-by-Week) مع ترتيب الأولوية والتأثير.
8. **قائمة Technical Debt** المتوقعة من نمط المشروع الحالي (SPA + router يدوي + SEO hooks) مع اقتراحات مستقبلية (مثل الانتقال إلى SSR/SSG إن لزم).

## 11) أسلوب الإخراج المطلوب
- اكتب بالعربية الواضحة.
- استخدم جداول حيث يفيد.
- كن عمليًا جدًا وابتعد عن التنظير.
- أعطني توصيات قابلة للتنفيذ مباشرة مع تقدير أثر كل توصية (High/Medium/Low).
